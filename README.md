# GRAVITY — Spatial Workshop

Интерактивная 3D‑мастерская DØMO ARCHITOYS для сборки архитектурных композиций из физических тел.

## Возможности

- семь типов тел: куб, сфера, цилиндр, конус, пирамида, плита и арка;
- физика столкновений с настройкой гравитации, упругости и трения;
- захват, перенос, масштабирование, фиксация, копирование и физические связи;
- отдельные светлая и тёмная темы без сброса сцены;
- WebXR для VR‑очков;
- захват VR‑контроллерами;
- WebXR hand tracking: щипок пальцами берёт, переносит и отпускает фигуру;
- пространственная палитра для создания тел прямо в VR.

## Запуск локально

```bash
npm install
npm run dev
```

## Netlify

В репозитории уже находится `netlify.toml`. При подключении репозитория Netlify использует:

- build command: `npm run build`
- publish directory: `dist/client`

WebXR работает только в безопасном контексте HTTPS. Netlify предоставляет HTTPS автоматически.

## VR

Откройте опубликованный HTTPS‑адрес в браузере совместимых очков и нажмите «Войти в VR». Контроллером объект берётся кнопкой выбора. При поддержке hand tracking сведите большой и указательный пальцы возле фигуры, переместите руку и разожмите пальцы. Такой же щипок по пространственной палитре создаёт новое тело.
